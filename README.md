# 🌱 AgroSmart — Agrinho 2026

## Tecnologia para uma agricultura sustentável

O **AgroSmart** é um projeto desenvolvido para o **Agrinho 2026**, com a proposta de utilizar a tecnologia para contribuir com uma agricultura mais sustentável.

A ideia do projeto é utilizar sensores para monitorar a umidade do solo e auxiliar no controle da irrigação, evitando o desperdício de água e promovendo o uso consciente dos recursos naturais.

---

## 🎯 Objetivo

O objetivo do AgroSmart é apresentar uma solução tecnológica que possa:

* 💧 Reduzir o desperdício de água;
* 🌱 Monitorar a umidade do solo;
* 📊 Utilizar dados para auxiliar na irrigação;
* 🌎 Incentivar práticas agrícolas sustentáveis;
* 💰 Contribuir para o uso mais eficiente dos recursos.

---

## 💡 Como funciona

O sistema apresenta uma simulação de um sensor de umidade do solo.

### 1. 📡 Sensor

O sensor verifica a umidade presente no solo.

### 2. 📊 Dados

As informações são analisadas pelo sistema.

### 3. 🧠 Decisão

Com base na umidade, o sistema identifica se o solo está seco, adequado ou muito úmido.

### 4. 💧 Irrigação

Quando o solo apresenta pouca umidade, o sistema recomenda a irrigação.

---

## 🖥️ Tecnologias utilizadas

O projeto foi desenvolvido utilizando:

* **HTML5** — estrutura da página;
* **CSS3** — aparência e responsividade;
* **JavaScript** — interatividade e simulação do sensor.

---

## 🌎 Sustentabilidade

A agricultura depende de recursos naturais essenciais. Por isso, utilizar a tecnologia para melhorar o controle da irrigação pode ajudar a evitar desperdícios e incentivar uma relação mais consciente com o meio ambiente.

O AgroSmart busca mostrar que **tecnologia e sustentabilidade podem trabalhar juntas para criar soluções para o campo**.
